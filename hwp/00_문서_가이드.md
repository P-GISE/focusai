## 읽는 순서

빠르게 구조만 파악하려면 `01 -> 02 -> 05` 순서로 읽습니다.

DB나 API 작업을 하려면 `03 -> 04 -> 07` 순서가 좋습니다.

프런트엔드 화면이나 학습 세션을 수정하려면 `02 -> 05 -> 06`을 먼저 봅니다.

배포나 운영 인수인계가 목적이면 `01 -> 08 -> 09 -> 99`를 봅니다.

현재 파일 점검 범위와 문서 반영 상태를 확인하려면 `10 -> 99` 순서로 봅니다.

## 문서 작성 원칙

- 실제 코드와 다르면 코드가 우선입니다.
- 비밀값, 실제 API 키, 실제 Discord 토큰은 문서에 기록하지 않습니다.
- 파일 경로는 `focusai-webapp/` 기준 상대 경로로 표기합니다.
- 운영 절차는 `README.md`와 `DEPLOYMENT.md` 중 최신 내용을 우선합니다.
- `docs/superpowers/` 아래 문서는 과거 계획/스펙 이력으로 보존합니다.
