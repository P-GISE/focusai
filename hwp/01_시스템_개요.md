# 01. 시스템 개요

## 목적

FocusAI는 학습 세션을 브라우저에서 기록하고, 트래킹 안정화가 반영된 집중도 타임라인과 리포트, AI 피드백, 공지, 문의/신고, 관리자 운영 기능을 제공하는 웹 애플리케이션입니다.

현재 구현은 단일 React SPA와 Express API 서버, MariaDB 저장소로 구성됩니다. 운영 보조 기능으로 FocusAI 관리자 Discord 봇과 Lost Ark Discord 봇 실행 관리도 포함합니다.

## 전체 구성

```text
Browser
  React SPA (Vite build: dist/)
  HttpOnly session cookie
  MediaPipe Tasks Vision
  localStorage session draft
        |
        | /api/*
        v
Express API server (:8787)
  auth/session/rate-limit/security headers
  MariaDB connection pool
  Anthropic Claude API client
  SMTP mailer
  FocusAI Discord in-process bot runtime
  Lost Ark Discord child-process bot gateway
        |
        v
MariaDB
  users, study_sessions, support_tickets,
  announcements, discord_bot_settings, ...

Android APK
  Capacitor Android shell
  Embedded Vite dist assets
  HTTPS API calls to focusai.ibetter.kr/api by default
  Optional hosted mode via CAPACITOR_SERVER_URL
  Camera permission declared in AndroidManifest.xml
```

운영에서는 Express 서버가 API와 정적 SPA 파일을 같은 컨테이너에서 제공합니다. 개발에서는 Vite dev server가 기본 `0.0.0.0:5173`, Express 서버가 `8787`에서 분리 실행됩니다. PC 브라우저는 `http://127.0.0.1:5173` 또는 `http://localhost:5173`로 접속하고, 같은 네트워크의 모바일 브라우저는 PC IPv4 주소를 사용해 `http://<PC_IP>:5173`로 접속합니다.

Android APK는 같은 React/Vite 앱을 Capacitor Android 프로젝트로 감싼 형태입니다. 기본 local APK는 `scripts/build-android-client.mjs`가 만든 `dist/` 정적 자산을 APK 안에 포함하고, 기본 API 주소는 `https://focusai.ibetter.kr/api`입니다. server APK는 `CAPACITOR_SERVER_URL=https://focusai.ibetter.kr`를 사용해 운영 웹을 여는 hosted 방식입니다. Android 최종 빌드는 로컬에 Android Studio 또는 Android SDK가 설치되어 있어야 합니다.

## 로컬 모바일 접근

`vite.config.ts`, `scripts/dev-client.mjs`, `scripts/preview-client.mjs`는 기본적으로 `FOCUSAI_CLIENT_HOST` 미설정 시 `0.0.0.0`에 바인딩합니다. 이 설정은 실제 휴대폰에서 로컬 UI와 API proxy를 확인하기 위한 것입니다.

- 모바일 로컬 URL: `http://<PC_IP>:5173`
- 현재 확인된 로컬 네트워크 예시: `http://192.168.0.2:5173`
- API proxy 확인: `http://<PC_IP>:5173/api/health`
- API 직접 확인: `http://<PC_IP>:8787/api/health`

PC에서만 열고 싶으면 실행 전에 `FOCUSAI_CLIENT_HOST=127.0.0.1`로 고정합니다. 실제 모바일 카메라 권한은 브라우저 보안 정책상 HTTPS 보안 컨텍스트가 필요하므로, 카메라 트래킹 최종 검증은 HTTPS 배포 주소에서 수행합니다.

## 런타임 플래그

`server/src/env.ts`는 환경변수를 검증하고 런타임 플래그를 계산합니다.

| 플래그 | 기준 | 영향 |
| --- | --- | --- |
| `mariaEnabled` | `MARIADB_HOST`, `MARIADB_USER`, `MARIADB_DATABASE` 존재 | false면 DB 의존 API는 503 응답 |
| `autoMigrateSchema` | `AUTO_MIGRATE_SCHEMA`, 미지정 시 비운영 환경에서 true | 서버 시작 시 `ensureSchema()` 실행 여부 |
| `anthropicEnabled` | `ANTHROPIC_API_KEY` 존재 | false면 AI 피드백은 로컬 분석 사용 |
| `allowRootDbInProduction` | `ALLOW_ROOT_DB_IN_PRODUCTION=true` | 운영 root DB 사용 차단 예외 |
| `smtpEnabled` | `SMTP_HOST`, `SMTP_FROM` 존재 | false면 비밀번호 재설정 메일 API는 503 |
| `smtpSecure` | `SMTP_SECURE=true` | SMTP TLS 옵션 |

운영 환경에서는 `APP_BASE_URL`과 `CLIENT_ORIGIN`이 HTTPS여야 하며, SMTP나 Anthropic 설정이 일부만 채워진 상태는 서버 시작 시 거부됩니다.

## 현재 구현상 특징

- `src/App.tsx`가 대부분의 화면 상태와 렌더링 함수를 포함하는 큰 컴포넌트입니다.
- `server/src/store.ts`가 대부분의 DB 쿼리와 비즈니스 로직을 보유합니다.
- 클라이언트와 서버 타입은 각각 `src/lib/contracts.ts`, `server/src/contracts.ts`에 분리되어 있어 수동 동기화가 필요합니다.
- FocusAI Discord 봇은 서버 내장 런타임과 `bot/src` standalone 구현이 함께 존재합니다.
- Lost Ark Discord 봇은 별도 Node 프로세스로 실행됩니다.
