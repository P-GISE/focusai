# 06. 프런트엔드 구조

프런트엔드는 React 19 + Vite + TypeScript 기반 SPA입니다. 진입점은 `src/main.tsx`, 핵심 화면과 상태 관리는 `src/App.tsx`에 집중되어 있습니다. 문서 title과 favicon은 `FocusAI` 서비스명 기준으로 정리되어 있습니다.

## 파일 구조

```text
src/
  main.tsx
  App.tsx
  App.css
  index.css
  html2pdf.d.ts
  assets/
  lib/
    api.ts
    contracts.ts
    cameraGuidance.ts
    discordBotDisplay.ts
    focusTracking.ts
    studyVision.ts
```

## 핵심 파일

### `src/App.tsx`

대부분의 화면 상태와 렌더링이 들어 있는 메인 컴포넌트입니다.

주요 책임:

- FocusAI 브랜드 로고와 상단 내비게이션 표시
- 인증 화면과 앱 화면 분기
- 서버 세션 쿠키 기반 로그인 복원 흐름 안내
- API 헬스체크와 MariaDB 연결 상태를 확인하고 서버 복구 시 bootstrap 자동 재시도
- 로그인/회원가입/비밀번호 입력 필드의 브라우저 자동완성 힌트 제공
- 대시보드, 세션 시작, 학습 진행, 결과, 리포트, AI 피드백 화면
- 대시보드 집중도 기간 전환(`이번 주`, `지난 주`, `최근 30일`)
- 공지, 문의/신고, 설정, 관리자 페이지
- 세션 draft 저장/복구
- MediaPipe 분석 결과를 학습 상태에 반영
- 오탐 방지용 트래킹 안정화 결과를 학습 점수와 근거 카드에 반영
- 관리자 Discord 봇 설정 form 관리

주요 화면 상태:

- `login`
- `camera`
- `dashboard`
- `announcements`
- `support`
- `session-setup`
- `learning`
- `result`
- `report`
- `feedback`
- `settings`
- `admin`

### `src/App.css`

전체 화면 스타일과 반응형 레이아웃을 담당합니다.

최근 반영된 주요 스타일:

- `.brand-mark`, `.brand-word`: FocusAI 로고와 서비스명 표시
- `.auth-brand-lockup`, `.auth-persistence-note`: 로그인 화면 브랜드 영역과 로그인 유지 안내
- `.focus-range-controls`: 대시보드 집중도 기간 전환 버튼
- `.learning-observation-pane`: 데스크톱 학습 화면에서 관찰 화면 고정
- `.learning-side-scroll`: 학습 화면 오른쪽 카드 목록 전용 스크롤
- `.tracking-card`, `.tracking-meter`: 학습 중 트래킹 안정성과 판정 근거 표시

### `src/lib/api.ts`

서버 API 호출 래퍼입니다.

담당:

- `requestJson` 기반 공통 fetch 처리
- 인증/계정 API
- 세션 저장/메모 수정
- AI 피드백 요청
- 공지/문의 API
- 관리자 API
- Discord 봇 설정/시작/중지 API

`getApiHealth()`는 `/api/health`가 실패하면 예외를 밖으로 던지지 않고 `apiReachable=false` 상태를 반환합니다. 로그인 화면은 이 값을 사용해 서버 연결 안내를 표시합니다.

### `src/lib/cameraGuidance.ts`

카메라 실패 상황을 사용자 행동 안내로 변환하는 순수 유틸입니다.

담당:

- 카메라 권한 거부, 장치 미감지, 장치 사용 중, 선택 장치 제약 오류 메시지 변환
- 카메라 복구 체크리스트 문구 제공
- MediaPipe 모델 로딩 실패 시 브라우저 기본 신호로 계속 측정한다는 fallback 안내 제공

### `src/lib/contracts.ts`

클라이언트 TypeScript 타입 정의입니다. 서버 Zod 스키마와 수동으로 동기화해야 합니다.

주요 타입:

- `UserProfile`
- `AppSettings`
- `LiveSession`
- `StoredSession`
- `Announcement`
- `SupportTicket`
- `AdminOverview`
- `DiscordBotSettings`
- `DiscordBotStatus`

### `src/lib/studyVision.ts`

MediaPipe FaceLandmarker 래퍼입니다.

기능:

- WASM과 모델 로딩
- 비디오 프레임 분석
- 얼굴 수, 프레이밍, 집중 상태 산출
- 얼굴 중심점과 얼굴 크기 비율 산출
- 머리 방향, 고개 각도, 눈 깜박임 점수 계산

모델 경로:

- WASM: `https://cdn.jsdelivr.net/npm/@mediapipe/tasks-vision@0.10.35/wasm`
- 모델: `/models/face_landmarker.task`

### `src/lib/focusTracking.ts`

카메라 분석 결과를 시간 축으로 안정화하는 순수 계산 모듈입니다.

목적:

- 순간적인 고개 회전, 눈 깜박임, 짧은 얼굴 미감지로 인한 오탐 감소
- 세션 초반 8초 동안 개인 기준 자세를 수집
- 최근 8초 점수 창을 사용해 집중도 점수를 급격히 흔들리지 않게 보정
- 얼굴 미감지 6초 이상, 고개/자세 이탈 5초 이상처럼 지속 조건을 만족할 때만 강한 판정 적용

주요 출력:

- `verdict`: `calibrating`, `stable`, `transient`, `distracted`, `away`, `unreliable`
- `score`: 안정화된 시각 트래킹 기반 점수
- `stability`: 트래킹 안정성 백분율
- `confirmedAway`, `confirmedDistraction`: 지속 조건을 통과한 확정 판정
- `reason`: 사용자에게 보여줄 판정 근거 문구

### `src/lib/discordBotDisplay.ts`

Discord 봇 상태 표시용 날짜/시간 포맷 유틸입니다.

### `index.html`과 `public/favicon.svg`

- `index.html`은 `lang="ko"`, title `FocusAI`, 설명 meta를 사용합니다.
- `public/favicon.svg`는 FocusAI 관찰/집중 의미를 담은 간단한 로고로 교체되어 있습니다.

## 로컬 상태 저장

클라이언트는 다음 localStorage 키를 사용합니다.

- `focusai:web:session-draft`: 진행 중 학습 세션 복구용
- `focusai:web:camera-device-id`: 마지막 선택 카메라 장치
- `focusai:web:last-screen`: 마지막 화면

세션 draft는 일정 시간이 지나면 무효화됩니다.

## API 연결

개발 시 Vite dev server는 `/api` 요청을 `http://127.0.0.1:8787`로 proxy합니다. dev/preview 클라이언트는 기본적으로 `0.0.0.0`에 바인딩되어 같은 네트워크의 모바일 브라우저에서도 로컬 UI를 확인할 수 있습니다.

관련 파일:

- `scripts/dev-client.mjs`
- `scripts/preview-client.mjs`
- `vite.config.ts`

관련 환경변수:

- `FOCUSAI_CLIENT_HOST`: dev server host override. 기본값은 `0.0.0.0`
- `FOCUSAI_PREVIEW_HOST`: preview server host override. 기본값은 `FOCUSAI_CLIENT_HOST` 또는 `0.0.0.0`
- `FOCUSAI_API_PROXY_TARGET`: `/api` proxy target override. 기본값은 `http://127.0.0.1:8787`

운영 빌드에서는 Express 서버가 `dist/` 정적 파일과 API를 함께 제공합니다.

인증 화면은 최초 진입 시 `/api/health`와 `/api/bootstrap`을 순서대로 확인합니다. 프런트엔드 dev server만 켜져 있고 API 서버가 아직 켜지지 않은 경우 `서비스 서버에 연결할 수 없습니다.` 안내를 표시합니다. 이후 `BACKEND_HEALTH_RETRY_MS` 기준으로 약 5초마다 헬스체크를 다시 수행하고, API와 MariaDB가 복구되면 `/api/bootstrap`을 다시 호출해 로그인 상태를 갱신합니다.

로컬 확인 명령:

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:5173/api/health
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:5173/api/bootstrap
```

모바일 로컬 확인:

```powershell
ipconfig
Invoke-WebRequest -UseBasicParsing http://<PC_IP>:5173/api/health
```

로컬 LAN의 `http://<PC_IP>:5173`에서는 화면과 API 연결을 확인할 수 있지만, 모바일 카메라 권한은 HTTPS가 아닌 환경에서 차단될 수 있습니다. 카메라 권한과 트래킹 세션은 HTTPS 배포 주소에서 최종 확인합니다.

## Android APK 프런트엔드 빌드

Android APK는 Capacitor가 `dist/` 정적 자산을 `android/app/src/main/assets/public`에 복사하는 방식입니다.

관련 파일:

- `capacitor.config.ts`: 앱 ID `kr.ibetter.focusai`, 앱 이름 `FocusAI`, `webDir=dist`
- `scripts/build-android-client.mjs`: Android용 Vite 빌드와 API 주소 주입
- `android/app/src/main/AndroidManifest.xml`: 인터넷/카메라 권한과 FocusAI 앱 아이콘
- `android/app/src/main/res/drawable/focusai_icon.xml`: Android 앱 아이콘 벡터

Android 웹 빌드는 기본 API 주소로 `https://focusai.ibetter.kr/api`를 사용합니다. 개발/테스트용 API가 다르면 `VITE_ANDROID_API_BASE_URL`로 덮어씁니다.

```powershell
$env:VITE_ANDROID_API_BASE_URL='https://focusai.ibetter.kr/api'
npm run android:apk
```

실제 APK 생성은 Android Studio 또는 Android SDK가 설치된 환경에서만 가능합니다.

현재 공유용 debug APK는 `focusai-webapp/apk-packages/`에 있습니다.

- `focusai-local-debug.apk`: 웹 리소스를 APK 안에 포함하고 운영 API를 호출하는 local APK
- `focusai-server-debug.apk`: `CAPACITOR_SERVER_URL=https://focusai.ibetter.kr`로 운영 웹을 여는 hosted/server APK
- `focusai-apk-pack.zip`: 위 두 APK를 함께 묶은 파일

두 APK 모두 debug 서명 산출물이므로 스토어 배포용은 아닙니다.

## 화면별 책임

### 인증 화면

- 회원가입
- 로그인
- 비밀번호 재설정 요청
- 비밀번호 재설정 완료
- 로그인 상태 유지 안내
- 서비스 서버 연결 실패 안내와 자동 재시도

로그인 유지는 서버의 HttpOnly 세션 쿠키와 `/api/bootstrap` 복원 흐름을 사용합니다. 클라이언트 API 호출은 `credentials: 'include'`를 사용해 쿠키를 포함합니다.

### 대시보드

- 오늘/선택 기간 학습 지표
- 집중도 흐름 기간 전환: `이번 주`, `지난 주`, `최근 30일`
- 최근 세션
- 과목별 평균
- 시간대별 패턴

### 세션 시작/학습 진행

- 과목/시간/모드 선택
- 카메라 권한과 장치 선택
- 집중 점수, 상태 메시지, 이벤트 로그 표시
- 목표 시간 도달 또는 수동 종료
- 데스크톱 학습 화면에서 왼쪽 관찰 화면은 고정하고 오른쪽 카드 목록만 스크롤
- 오른쪽 카드 목록에 트래킹 안정성, 개인 기준선 적용 여부, 오탐 방지 판정 근거 표시

집중도 계산은 현재 프레임의 감지만 바로 사용하지 않고 `focusTracking.ts`의 안정화 결과를 우선 반영합니다. 짧은 고개 회전이나 순간 미감지는 `transient`로 표시하고, 지속 시간이 기준을 넘을 때만 `distracted` 또는 `away`로 확정합니다.

- Anthropic 또는 local source 표시
- 강점/주의점/전략/패턴 표시

### 공지/문의

- 공지 목록과 활성 공지
- 문의 접수 form
- 내 문의 목록

### 설정

- 프로필
- 과목
- 세션 기본값
- 알림과 화면 설정
- 보안/계정 관리

### 관리자

- 관리자 개요

- 시스템 상태

## 회귀 검증

프런트엔드 요청 반영 여부는 `focusai-webapp/docs/focusai-ui-regression.test.ts`에서 문서성 회귀 테스트로 확인합니다.

검증 대상:

- `index.html`의 한국어 문서 언어와 `FocusAI` title
- 로그인 상태 유지 안내와 쿠키 포함 API 흐름
- 서버 헬스체크 실패 후 자동 재시도 루프
- 모바일 로컬 접근용 `0.0.0.0` dev/preview host 설정
- 대시보드 기간 전환 옵션
- 학습 화면 관찰 영역 고정/오른쪽 패널 스크롤 클래스
- 관련 CSS 클래스 존재 여부

트래킹 안정화 로직은 `focusai-webapp/docs/focus-tracking.test.ts`에서 순수 함수 테스트로 확인합니다.

검증 대상:

- 짧은 고개 회전은 `transient`로 유지되어 집중 이탈 확정이 되지 않음
- 얼굴 미감지는 6초 이상 지속될 때만 `away`로 확정
- 확정 자리 비움은 안정화 평균을 쓰더라도 낮은 점수로 제한

Android APK 패키징은 `focusai-webapp/docs/android-apk.test.ts`에서 문서성 회귀 테스트로 확인합니다.

검증 대상:

- Capacitor 의존성, 앱 ID, 앱 이름, `webDir`
- Android 전용 웹 빌드 스크립트와 npm scripts
- Android 프로젝트, 카메라 권한, 앱 아이콘
- README의 APK 빌드 명령 안내
