# 07. 백엔드 구조

백엔드는 Express 5 + TypeScript 기반입니다. 개발 실행은 `npm run dev:server`, 운영 실행은 `node server/dist/index.js`입니다.

## 파일 구조

```text
server/src/
  index.ts
  load-env.ts
  env.ts
  contracts.ts
  auth.ts
  store.ts
  mariadb.ts
  rate-limit.ts
  security-headers.ts
  password-policy.ts
  session-time.ts
  insights.ts
  anthropic.ts
  ai-budget.ts
  mailer.ts
  discord-bot-manager.ts
  discord-bot-secrets.ts
  discord-bot-gateway.ts
  process-discord-bot-gateway.ts
  lostark-discord-bot-runtime.ts
  init-db.ts
```

## 주요 모듈

### `index.ts`

Express 앱 구성과 라우팅 진입점입니다.

담당:

- JSON body parsing
- CORS
- 보안 헤더
- API no-store 정책
- rate limit 구성
- 인증/관리자 미들웨어 적용
- 모든 REST API 라우트 등록
- 정적 SPA 서빙
- 서버 시작 시 schema 보정과 Discord 봇 자동 시작

### `load-env.ts`

로컬 실행 시 `.env.server`, `.env`를 순서대로 로드합니다. 이미 존재하는 환경변수를 덮어쓰지 않습니다.

### `env.ts`

환경변수를 Zod로 파싱하고 운영 검증을 수행합니다.

운영 검증:

- `APP_BASE_URL`, `CLIENT_ORIGIN` HTTPS 강제
- boolean 값은 `true`/`false`만 허용
- SMTP 부분 설정 차단
- Anthropic 사용 시 단가 값 검증
- 운영 root DB 사용 차단

### `contracts.ts`

서버 요청/응답 검증 스키마와 payload 타입입니다.

주요 스키마:

- 인증/계정
- 프로필/설정
- 세션 저장/메모 수정
- 관리자 role 변경
- Discord 봇 설정
- 공지
- 문의
- 관리자 overview

### `auth.ts`

인증 미들웨어와 쿠키 처리 모듈입니다.

담당:

- 세션 쿠키 생성/삭제
- `requireAuth`
- `requireAdmin`
- 요청 세션 파싱
- 현재 세션 폐기

### `store.ts`

DB 접근과 대부분의 비즈니스 로직을 담고 있습니다.

주요 기능:

- 사용자 가입/로그인/삭제
- 비밀번호 변경/재설정
- 세션 저장/조회/메모 수정
- 프로필과 설정 저장
- 공지 CRUD
- 문의 생성/처리
- 관리자 overview 조회
- 감사 로그 기록
- Discord 봇 설정 저장/조회/상태 갱신
- AI 사용량 기록

현재 가장 큰 모듈이므로 장기적으로 도메인별 분리가 필요합니다.

### `mariadb.ts`

MariaDB connection pool과 스키마 초기화/보정을 담당합니다.

담당:

- pool 생성
- `withConnection`
- `pingMaria`
- `ensureSchema`
- 누락 컬럼 보정

### `rate-limit.ts`

메모리 기반 rate limit 구현입니다. 단일 프로세스 기준으로 동작합니다.

적용 영역:

- 인증
- 계정/문의
- AI
- 관리자 API

### `security-headers.ts`

기본 보안 헤더를 생성합니다.

포함 항목:

- CSP
- Google Fonts 허용(`fonts.googleapis.com`, `fonts.gstatic.com`)
- HSTS
- X-Frame-Options
- X-Content-Type-Options
- Referrer-Policy

### `password-policy.ts`

비밀번호 강도 정책을 검증합니다. 인증 관련 Zod 스키마에서 사용합니다.

### `session-time.ts`

클라이언트가 보낸 세션 생성 시각이 미래이거나 너무 오래된 경우 서버 시각으로 보정합니다.

### `anthropic.ts`, `ai-budget.ts`, `insights.ts`

AI 피드백 관련 모듈입니다.

- `anthropic.ts`: Anthropic Messages API 호출
- `ai-budget.ts`: 일일 요청량/예산 검사
- `insights.ts`: 로컬 fallback 분석 생성

### `mailer.ts`

Nodemailer 기반 비밀번호 재설정 메일 발송 모듈입니다.

### `discord-bot-manager.ts`

봇 런타임 상태를 관리하는 공통 매니저입니다.

상태:

- `disabled`
- `starting`
- `running`
- `stopping`
- `error`

### `discord-bot-secrets.ts`

Discord 봇 토큰 암호화/복호화 모듈입니다.

지원 형식:

- 개발: `local:` prefix 저장 가능
- 운영: `aes-256-gcm:` 암호화 저장

운영 secret 해석 순서:

1. `DISCORD_BOT_SETTINGS_SECRET`
2. `uploads/.focusai-secrets/discord-bot-settings-secret` 자동 생성/재사용

### `discord-bot-gateway.ts`

FocusAI 관리자 Discord 봇의 서버 내장 런타임입니다.

담당:

- 14개 slash command 등록
- guild/channel/role guard
- 문의/공지/사용자/세션/감사 로그 명령 처리
- 문의 상태 버튼 처리
- 문의/상태/일일 요약 알림
- 알림 채널 설정 파일 저장

### `process-discord-bot-gateway.ts`

외부 봇 프로젝트를 Node 하위 프로세스로 실행하는 게이트웨이입니다. Lost Ark 봇에 사용됩니다.

담당:

- 봇 디렉터리와 entrypoint 확인
- 명령 deploy entrypoint 실행
- 봇 프로세스 실행
- 초기 종료 감지
- stdout/stderr prefix logging
- stop 처리

### `lostark-discord-bot-runtime.ts`

운영 번들에서 Lost Ark 봇 data 파일을 `uploads/lostark-discord-bot`로 seed/merge합니다.

## 서버 시작 흐름

1. `load-env.ts`가 환경변수를 로드합니다.
2. `env.ts`가 환경변수를 파싱/검증합니다.
3. Express 앱을 구성합니다.
4. `AUTO_MIGRATE_SCHEMA`가 true이면 `ensureSchema()`를 실행합니다.
5. `discord_bot_settings.enabled=true`인 봇을 자동 시작합니다.
6. `PORT`에서 listen합니다.

## 테스트

서버 테스트는 Node 내장 test runner와 `tsx`를 사용합니다.

대표 명령:

```powershell
node --import tsx --test server/src/*.test.ts
```

현재 테스트 범위:

- Discord 봇 명령 동기화
- Discord 봇 manager/secrets/process gateway
- 환경변수 검증
- 메일 reset URL
- 비밀번호 정책
- 세션 시각 보정
- 보안 헤더
