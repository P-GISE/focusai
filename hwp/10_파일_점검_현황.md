## 현재 주의할 점

- 실제 운영 `.env`와 로컬 `.env`는 문서에 값을 남기지 않는다.
- 프로젝트 밖으로 격리한 `token.json`과 `android/local.properties`처럼 토큰이나 로컬 SDK 경로를 담을 수 있는 파일도 값은 문서화하지 않는다.
- `lostark-discord-bot/data/*.json`에는 로컬 데이터 변경이 존재하므로, 정리나 되돌리기는 별도 확인 후 진행한다.
- 기존 상위 `디스코드 봇/` 중복 복사본은 프로젝트 밖 백업으로만 보관하고, `focusai-webapp` 배포 대상에는 포함하지 않는다.
- Android debug APK는 테스트용이다. 스토어 등록 전에는 signing config, keystore 보관, Android App Bundle 절차가 필요하다.
- iPhone 배포는 APK가 아니라 Xcode 기반 iOS 빌드, IPA/TestFlight, App Store 절차가 필요하다.
